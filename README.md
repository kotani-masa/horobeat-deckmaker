# ホロビート デッキメーカー

ホロビートカードゲームのデッキ構築ツールです。

**https://kotani-masa.github.io/horobeat-deckmaker/**

- 下の候補カードを上へドラッグしてデッキに追加（同名カードは自動でまとまります）
- デッキのカードはドラッグで並べ替え、下へはじくと削除
- コスト帯・色・カードタイプの分析、デッキコード／共有URL、10×5のデッキ画像保存

## カードデータの更新

カードデータは公式カード検索から取得して `index.html` に埋め込んでいます。新しいカードが出たら:

```sh
node update_cards.mjs index.html
```

カード画像・カード情報の権利は各権利者に帰属します。非公式のファンツールです。
